About Sreelekha Parking System

Technical overview, design specifications, and database schema documentation.

Project Abstract

The Sreelekha Parking Lot Management System is a full-stack multipage web application built for managing vehicle parking operations, slot allocation, duration tracking, and checkout fee calculations in parking facilities, commercial complexes, and academic institutions.

Core Project Objectives

  • Automate vehicle intake and owner registration with relational integrity.
  • Dynamically allocate compatible parking slots (Cars vs Bikes vs Any).
  • Track real-time slot occupancy across multiple zones and floors (Ground Floor, Basement, Upper Levels).
  • Accurately log entry and exit timestamps using MySQL timestamp functions.
  • Calculate duration-based parking charges with automated ceiling rounding.
  • Generate professional printable parking tickets and tax invoices upon exit.

Relational Database Schema (MySQL)

The system implements four normalized relational tables with foreign key constraints:

1. Table: users

Stores system administrators, security operators, and customers.

user_id (INT PK), name (VARCHAR), phone (VARCHAR), email (VARCHAR UNIQUE), role (ENUM)
2. Table: parking_slots

Physical parking bays with vehicle compatibility, floor location, and live status.

slot_id (INT PK), slot_number (VARCHAR UNIQUE), vehicle_type (ENUM), location (VARCHAR), status (ENUM)
3. Table: vehicles

Customer vehicle registrations linked to owners.

vehicle_id (INT PK), user_id (INT FK), vehicle_number (VARCHAR UNIQUE), vehicle_type (ENUM), vehicle_model (VARCHAR)
4. Table: parking_records

Comprehensive transaction log recording bay assignment, duration, fees, and completion.

record_id (INT PK), vehicle_id (INT FK), slot_id (INT FK), entry_time (DATETIME), exit_time (DATETIME), parking_fee (DECIMAL), status (ENUM)

🏍️

Two-Wheeler (Bike)

₹15.00 / hour

Applicable to motorcycles, scooters, and mopeds.

Calculation Formula: Fee = GREATEST(1, CEIL(Elapsed_Minutes / 60)) × Hourly_Rate
Minimum billing duration is 1 hour. Any started hour is rounded up to the nearest whole hour.
